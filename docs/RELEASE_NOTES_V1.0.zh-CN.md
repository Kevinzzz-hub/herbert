# Herbert V1.0 发布说明

Herbert V1.0 是第一个可以公开使用的完整版本。

正式网址：<https://herbert-pdf-reader.vercel.app/>

## 核心能力

- 使用邮箱 8 位验证码登录，不保存密码；
- 以课程为单位管理多份文字型 PDF；
- 生成带原文页码的全文总结；
- 对单份文档或整个课程进行有证据的问答；
- 根据原文生成复习卡片和五道测验题；
- 在浏览器中保存课程，并支持导出和恢复备份；
- 每位用户连接自己的 AI API Key，平台不承担模型调用费用；
- 支持 DeepSeek、OpenAI、Google Gemini、Anthropic Claude 和 OpenRouter。

## 安全与隐私边界

- 原始 PDF 不上传保存；浏览器只提取可读文字；
- API Key 由 Supabase Vault 加密保存，保存后不会返回浏览器；
- AI 请求必须携带当前用户的登录令牌；
- 课程数据按用户 ID 隔离，并保存在当前浏览器；
- PDF 中出现的指令被当作不可信内容，不会覆盖 Herbert 的系统规则。

## 已知限制

- 仅支持包含可选择文字的 PDF，不支持扫描件 OCR；
- 复杂表格、图片和排版可能导致文字拼接错误；
- 课程默认只保存在当前浏览器，不会自动同步到其他设备；
- 邮件验证码的送达速度取决于 Brevo 和收件邮箱，Gmail 偶尔可能延迟或进入垃圾邮件；
- 重新发送验证码后，较早邮件中的验证码会失效，应以页面显示的发送时间为准；
- V1.0 不提供 Google 登录；
- AI 输出仍可能出错，重要结论应根据页码回到原文核对。

## 为什么现在称为 V1.0

V1.0 不代表产品已经没有缺点，而是代表一条核心用户流程已经完整：登录、连接 AI、建立课程、上传 PDF、总结、问答、复习、保存和恢复。后续版本将优先处理真实用户反馈，而不是继续无边界增加功能。
