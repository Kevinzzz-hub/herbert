# Herbert V0.7：课程级多 PDF 联合问答

## 这个模块解决什么问题

V0.6 的问答范围是一份 PDF。V0.7 在课程页面增加“问整门课”，让 Herbert 可以从同一课程的多份 PDF 中寻找证据并综合回答。

回答必须显示来源文件名和原 PDF 页码。课程资料没有足够证据时，Herbert 会明确说明，而不是依靠常识补写。

## 工作流程

1. 浏览器读取当前课程已经保存的 PDF 文字。
2. 浏览器根据问题给每一页计算相关度。
3. 每份 PDF 最多选择 4 页，整次最多选择 10 页、约 18,000 个字符。
4. 只有这些相关文字片段、问题和最近对话会发送给 DeepSeek。
5. 服务端验证 DeepSeek 返回的每一个“文件 + 页码”确实存在于本次证据中。
6. 页面显示联合回答和可以回查的来源。

这个过程属于 RAG（Retrieval-Augmented Generation，检索增强生成）的简化版本：先检索证据，再让模型依据证据生成答案。

## 隐私边界

- 原 PDF 文件不会上传。
- 整门课程的全部文字不会一次性发送。
- DeepSeek API Key 继续只在服务端读取。
- 课程、提取文字和学习记录继续保存在当前浏览器。
- 清除浏览器数据仍会删除本机课程，因此需要定期导出课程备份。

## 当前限制

- 只支持已经成功提取文字的 PDF，不支持扫描图片 PDF。
- 本地相关度检索依赖问题与原文中的词语匹配；同义表达可能漏掉部分页面。
- 一次最多使用 10 页证据，避免请求过长和不必要的 API 费用。
- V0.7 不保存课程问答历史；离开课程后对话会重新开始。

## 验收方法

准备至少两份属于同一课程的 PDF，然后：

1. 进入课程，确认“问整门课”显示可检索 PDF 数量。
2. 提出一个需要比较或综合的问题。
3. 确认回答显示文件名和页码。
4. 提出一个课程资料完全无关的问题，确认 Herbert 提示证据不足。
5. 打开单份 PDF 总结，确认原来的单 PDF 问答仍然可用。
